# Devanshu Raturi — portfolio

Personal portfolio of Devanshu Raturi (founder, Neev Automation): websites, online stores and WhatsApp AI automation.

Live: https://devanshu-portfolio-mocha.vercel.app

## Stack
Next.js 14 (App Router) · TypeScript · Tailwind CSS · Framer Motion · Lenis

## Edit content
All copy, links and projects live in `src/data/site.ts`. Colours and fonts live in `tailwind.config.ts`.
Hero portrait: replace `public/img/hero-portrait.jpg` (keep the name).

## Run
```bash
npm install
npm run dev
```
